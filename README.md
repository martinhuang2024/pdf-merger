# 合頁 PDF 合併工具

一個完全在瀏覽器本機運作的多 PDF 合併工具。可加入多份 PDF、使用已知密碼解鎖、查看頁數與大小、調整順序、設定下載檔名並合併下載，並支援深色模式。

## 線上使用

GitHub Pages：https://martinhuang2024.github.io/pdf-merger/

網站由獨立公開儲存庫部署；PDF 與密碼仍只會在瀏覽器本機處理，不會上傳到伺服器。

## 使用方式

直接開啟 `index.html`：

1. 點擊「把 PDF 放到這裡」或拖入多份 PDF。
2. 加密 PDF 會先顯示檔案名稱與「已加密」，點擊該列的「去除密碼」。
3. 確認視窗中的檔案名稱，輸入這份 PDF 的已知密碼。
4. 使用拖曳或上下按鈕調整合併順序。
5. 如需統一方向，勾選「統一頁面方向」並選擇直向或橫向；未勾選會保留原始混合方向。
6. 可點檔案列的「預覽」查看單檔，或點「預覽合併結果」確認目前設定。
7. 設定下載檔名後點擊「合併並下載」。

解鎖成功的檔案會顯示「已去除密碼」與「單獨下載」按鈕，下載檔名預設為 `原檔名_已解密.pdf`；合併輸出也不含密碼。PDF 與密碼只會在目前瀏覽器記憶體中處理，不會上傳至伺服器。

頁面右上角可切換深色或淺色模式。第一次開啟會跟隨裝置設定，手動切換後會記住選擇。

## 技術

- Vue 3 本地版本：`vendor/vue.global.prod.js`
- PDF 合併引擎：`vendor/pdf-lib.min.js`
- PDF 預覽引擎：PDF.js（本機畫布渲染）
- PDF 解鎖引擎：QPDF WebAssembly（本地內嵌）
- 不依賴外部網路或建置工具
